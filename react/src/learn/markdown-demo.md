# Markdown 渲染演示

这是一段普通段落, 支持 **加粗**、*斜体*、~~删除线~~ 和 `行内代码`,
也能内嵌 [超链接](https://react.dev); 段落之间用空行分隔。

## 二级标题

### 三级标题

- 无序列表项
- 嵌套子列表:
  - 子项 A
  - 子项 B

1. 有序列表第一项
2. 有序列表第二项

- [x] 任务列表: 已完成(勾选)
- [ ] 任务列表: 未完成

> 引用块: 适合强调一段话或摘录内容,
> 连续多行会自动接上左侧竖线。

| 写法 | 渲染结果 | 备注 |
| --- | --- | --- |
| `**文字**` | **加粗** | 最常用 |
| `[文字](url)` | [链接](https://react.dev) | 外链 |
| `~~文字~~` | ~~删除线~~ | GFM 扩展 |
